# Privacy Policy for TubeCourier

**Effective Date:** October 20, 2026  
**Repository:** [https://github.com/covarianttensor/TubeCourier](https://github.com/covarianttensor/TubeCourier)

TubeCourier is committed to protecting your privacy. This privacy policy explains what data the extension accesses, how it is used, and why specific browser permissions are requested.

---

## 1. Zero Telemetry & No Tracking

- **No Remote Author Servers:** The developer does not operate any analytics servers, tracking endpoints, crash reporting services, or cloud relays.
- **No Data Harvesting:** TubeCourier does not log, track, sell, or collect your browsing history, personal data, or usage metrics.
- **Direct Local Communication:** All network traffic generated by TubeCourier occurs exclusively between your web browser and the self-hosted backend server address that **you explicitly configure** (e.g., `http://localhost:8081` or `http://192.168.1.100:8081`).

---

## 2. Browser Permissions Justification

TubeCourier requires specific browser permissions to interact with your media tabs and communicate with your self-hosted download backend:

| Permission | Purpose & Scope |
| :--- | :--- |
| `cookies` | Accessed **only** when queuing a download (if "Sync Cookies" is enabled). It extracts active YouTube/Google authentication cookies for the current session and transmits them directly to your self-hosted instance (via `POST /upload-cookies`). This allows your server's `yt-dlp` engine to bypass bot checks and download age-restricted or member-only videos. Cookies are never stored remotely or shared with any third party. |
| `tabs` & `activeTab` | Inspects the active browser tab to identify whether you are viewing a supported video page, pre-populating the URL and video title inside the extension popup. |
| `<all_urls>` | Required because self-hosted download servers can reside on any arbitrary IP address, local network subnet (`10.0.0.0/8`, `192.168.0.0/16`), or custom domain/port. Additionally required for `webRequest` header interception targeting your server. |
| `storage` | Stores your extension settings (such as backend server URL, default format preference, cookie sync toggle, and category chips) locally inside your browser profile using `browser.storage.local`. No data leaves your machine. |
| `notifications` | Triggers native desktop/system notifications when a download finishes or encounters an error on your server. |
| `contextMenus` | Adds a right-click menu item ("Download with TubeCourier") on media links and pages to queue videos directly. |
| `webRequest` & `webRequestBlocking` | Used solely to adjust outgoing `Origin` headers on requests sent to your self-hosted server address. This bypasses backend CORS/Origin security blocks without requiring you to relax server configuration. |

---

## 3. Data Storage & Retention

- **Configuration:** Stored exclusively in your browser's private local storage (`browser.storage.local`).
- **Cache & History:** Active and finished download items are cached in memory and local storage to display the queue within the popup. You can clear this history at any time using the "Clear Finished" button.
- **Removal:** Uninstalling the extension permanently purges all stored preferences and cached queues.

---

## 4. Third-Party Code

TubeCourier bundles a single standalone vendor library:
- **Socket.IO Client v4.7.5** (`lib/socket.io.min.js`), licensed under the MIT License.
- This library connects only to your configured server to receive real-time download progress events.

---

## 5. Security & Verification

TubeCourier is fully open source. You can audit the entire codebase, verify all network requests in your browser's developer tools (`about:debugging`), or build the `.xpi` package yourself from source.

For questions, issues, or security disclosures, please open an issue on the [GitHub Repository](https://github.com/covarianttensor/TubeCourier/issues).
